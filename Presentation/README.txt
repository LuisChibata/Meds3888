Thera-Fits: Allysa's walkthrough, for the final presentation

TO RUN
Double-click index.html, then press Play. It works like the public walkthrough (Explainer/story.html), which
hasn't changed: pause, step with the arrow keys, drag the bar, or jump to a chapter. No internet needed.
Each step lasts about as long as saying its words, so Luis and Allysa can perform along with it.
Keep this folder next to Explainer/, because it uses Explainer's data, matching rules and photos.
To move it to another laptop, copy both folders together (Presentation and Explainer).

TIMING
Open "Change the timing" under the player. Set seconds for the whole walkthrough, a chapter or a step, and
tick "Stop after" where Play should wait for a press. It's remembered in that browser only. To use the same
timing elsewhere, use "Copy a link with this timing" (index.html?t=...).

PRESENTER MODE
The Presenter mode button (or index.html?live) is the same story full screen. Nothing moves on until you click:
  Mouse click, right arrow, PageDown, Space, Enter         next step
  Right-click, left arrow, PageUp, Backspace               back one step, without animating
  Home                                                     back to the start
  Esc                                                      leave presenter mode
  B or .                                                   black screen on or off
  N                                                        show or hide the cue number (bottom right)
  F                                                        full screen on or off
index.html?live&cue=10 opens cue 10. The [CUE n] marks in the working script date from before the story was split
into smaller steps, so they don't match yet.

BEFORE PRESENTING
- Check for a banner saying "Don't present this yet". It appears if the matching data changes and the story
  stops being true.
- To change how the cartoons look, edit the --allysa-* and --vanessa-* colours at the top of index.html.
- This folder is published at /Presentation/ on the Netlify site and linked from the menu on every page, so
  anyone on the site can open it. Search engines are asked not to list it. The working script (*.md) stays local.
